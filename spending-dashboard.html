Make this your dashboard
This whole thing is one HTML file built with Claude. You can fork it, add the metrics you actually care about, and rebuild it in minutes — no coding.
1
Save this page to your computer (⌘S / Ctrl+S) so you have the HTML file.
2
Open claude.ai, start a new chat, and upload the HTML file.
3
Paste this prompt to get started — change the part in [brackets] to whatever you want:
This is a personal spending dashboard built as a single HTML file. I want you to add [a savings rate KPI that compares my spending to a monthly income I'll set]. Keep the existing design system, fonts, and color palette. Return the full updated HTML file.
4
Claude returns a new HTML file. Save it, open it in your browser — done. Your version, your metrics.
